# Customer-Analytics-CLV-Churn
**Customer Churn Prediction Dashboard**
**Project Overview**
The Customer Churn Prediction Dashboard is an interactive web application built with Streamlit that allows users to:<br>
Upload and visualize customer transaction data

Analyze churn patterns using interactive charts

Predict customer churn based on RFM (Recency, Frequency, Monetary) metrics using a trained Machine Learning model

Make data-driven decisions to improve customer retention

This project is focused on combining business analytics with ML and visual storytelling.

**🛠️ Tools & Technologies Used**

**Python**	Core programming language

**Pandas / NumPy**	Data cleaning & transformation4

**Matplotlib / Seaborn**	Data visualization

**scikit-learn**	ML model development

**Streamlit**	Frontend dashboard interface

**Joblib**	Model serialization

**VS Code/Google Colab**  Development environment

**🧩 Features**
Upload your own customer CSV data with a Churn column

View churn distribution via pie charts

Enter customer metrics to predict churn probability

Clean, responsive design powered by Streamlit

**Future scope for:**
Segment-based filtering

Integration of Power BI dashboards

Churn explanation using SHAP

**⚙️ How to Run This Project Locally**

**Clone this repository**

git clone https://github.com/yourusername/churn-dashboard.git

cd churn-dashboard

**Install dependencies**

It is recommended to use a virtual environment.

pip install -r requirements.txt

**Run the app**

streamlit run dashboard.py

**Upload a CSV file with a Churn column and explore the dashboard!**

**🧠 ML Model Training:**

**If you want to retrain the churn model:**

python churn_model.py

This will train and save churn_model.pkl in your project directory.
